AI rådgiver

Tilføj din egen AI nøgle

Rådgiveren bruger din egen API nøgle. Den gemmes kun på din profil og bruges kun til at svare dig. Du betaler selv forbruget hos udbyderen.

Indstillinger gemt.
Ukendt udbyder. Du mangler at indsætte en API nøgle. Noget gik galt. Prøv igen.
Hvis slået fra, forsvinder knappen i hjørnet.
Nøglen vises aldrig i klartekst igen. Lad feltet være tomt for at beholde den eksisterende.
Lad være tom for at bruge en fornuftig default.
Tilbage

Sådan får du en nøgle

Claude (Anthropic)

  1. Opret konto på console.anthropic.com
  2. Gå til Settings → API Keys
  3. Klik Create Key og kopier den (den starter med sk-ant-)
  4. Indsæt den her i feltet

GPT (OpenAI)

  1. Opret konto på platform.openai.com
  2. Gå til API keys i venstre menu
  3. Klik Create new secret key (starter med sk-)
  4. Indsæt den her

Hvad koster det?

Rådgiveren bruger små mængder: typisk 1 til 3 ører per svar med Claude Haiku, lidt mere med GPT-4o-mini. Du har også en rate limit på 30 beskeder i timen for ikke at løbe løbsk.
